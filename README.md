# Insider Threats in Cybersecurity

## Project Overview

This academic project examines insider threats in cybersecurity, focusing on how individuals within an organisation can intentionally or unintentionally compromise information systems, sensitive data, and organisational security.

It explores the causes and motivations behind insider threats, their potential impacts on organisations, and the security measures that can help prevent, detect, and mitigate insider-related security incidents.

## Research Objectives

- Examine the concept and different categories of insider threats.
- Identify the human, organisational, and technical factors that contribute to insider security risks.
- Explore the consequences of insider threats on organisational information systems.
- Examine security strategies for preventing, detecting, and mitigating insider threats.

## Key Areas Covered

- Insider threat types and classifications
- Human factors and employee behaviour
- Organisational security vulnerabilities
- Insider threat detection and prevention
- Risk management and security controls
- Incident response and mitigation strategies
